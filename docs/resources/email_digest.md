# mixpanel_email_digest (Resource)

Manages a Mixpanel **email digest** (`mixpanel_email_digest`) — a scheduled delivery of a board (dashboard) snapshot sent to specified recipients via email or Slack.

## Example Usage

```terraform
resource "mixpanel_email_digest" "weekly_kpis" {
  name         = "Weekly KPIs"
  dashboard_id = 123
  recur        = 7
  recipients   = ["team@example.com"]
  paused       = false
  start_date   = "2024-01-15"
  timezone     = "America/Los_Angeles"
}
```

## Update Semantics

Email digest updates use `PATCH` and accept only `name`, `dashboard_id`,
`deleted`, `paused`, `recipients`, `recur`, `monthly_week_ordinal`,
`start_date`, `tag`, `timezone`, and `slack_subscriptions`;
`schedule_timezone` is create-only and is not sent on update.
