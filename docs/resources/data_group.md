# mixpanel_data_group (Resource)

Manages a Mixpanel **data group** — the join key that enables group analytics
(tracking at the account or organization level) or backs a lookup table. Each
data group links a property name (the join key) to a display name and optional
metadata.

## Example Usage

```terraform
resource "mixpanel_data_group" "accounts" {
  project_id = 1234567

  display_name  = "Accounts"
  property_name = "account_id"

  metadata = {
    is_company_key      = true
    company_key_name    = "account_id"
    company_revenue_key = "mrr"
  }
}
```

## Related Resources

- [mixpanel_lookup_table](lookup_table.md) — creates a dimension data group and uploads CSV data keyed by the join column.
