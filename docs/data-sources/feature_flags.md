# mixpanel_feature_flags (Data Source)

Lists all feature flags in a Mixpanel project. Returns raw IDs and composite import IDs for bulk adoption workflows.

## Example Usage

```terraform
data "mixpanel_feature_flags" "all" {
  project_id = 1234567
}

# Bulk import feature flags into Terraform state
import {
  for_each = toset(data.mixpanel_feature_flags.all.import_ids)
  to       = mixpanel_feature_flag.imported[each.value]
  id       = each.value
}

resource "mixpanel_feature_flag" "imported" {
  for_each = toset(data.mixpanel_feature_flags.all.ids)
  # lifecycle block prevents Terraform from modifying imported flags
  lifecycle {
    ignore_changes = all
  }
}
```

See the [bulk import guide](../guides/import.md) for detailed workflows.
