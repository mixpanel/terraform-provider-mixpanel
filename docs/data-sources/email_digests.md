# email_digests (Data Source)

Lists every Mixpanel email digest in a project — use it to discover digest IDs and to bulk-import with `for_each`. See also [`mixpanel_email_digest` data source](email_digest.md) and [`mixpanel_email_digest` resource](../resources/email_digest.md).

## Example Usage

```terraform
data "mixpanel_email_digests" "all" {
  project_id = 1234567
}
```

Returns `ids` (list of raw email digest IDs) and `import_ids` (list of `PROJECT_ID:DIGEST_ID` composites ready to feed `for_each` import blocks). See the [import guide](../guides/import.md) for the bulk-import pattern.
