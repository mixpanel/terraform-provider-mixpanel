# org_request_access_settings (Data Source)

Reads organization-level settings controlling how users request access to the organization. These settings determine approval workflows and access request behavior.

## Example Usage

```terraform
data "mixpanel_org_request_access_settings" "current" {
  organization_id = 9876543
}
```

See the [mixpanel_org_request_access_settings](../resources/org_request_access_settings.md) resource to manage these settings.
