# mixpanel_experiments (Data Source)

Lists all experiments in a Mixpanel project. Returns raw IDs and composite import IDs for bulk adoption workflows.

## Example Usage

```terraform
data "mixpanel_experiments" "all" {
  project_id = 1234567
}
```

Returns `ids` (list of raw experiment IDs) and `import_ids` (list of `PROJECT_ID:ID` composites ready to feed `for_each` import blocks). See the [import guide](../guides/import.md) for the bulk-import pattern.

## Bulk import with `for_each`

Adopt every experiment in the project in one pass: the list data source's `import_ids`
feed a `for_each` [import block](../guides/import.md), and `-generate-config-out`
scaffolds each resource body for review before you apply.

```terraform
data "mixpanel_experiments" "all" {}

# One import per experiment. Both for_each iterate import_ids, so the import block
# and the resource address share the same instance key.
import {
  for_each = toset(data.mixpanel_experiments.all.import_ids)
  to       = mixpanel_experiment.this[each.key]
  id       = each.value
}

resource "mixpanel_experiment" "this" {
  for_each = toset(data.mixpanel_experiments.all.import_ids)
  # Body scaffolded by `terraform plan -generate-config-out=generated.tf`,
  # then reviewed and edited before apply.
}
```

Run `terraform plan -generate-config-out=generated.tf`, review the generated
configuration, then `terraform apply` to import every experiment. Set `project_id`
on the data source to target a non-default project. See the
[import guide](../guides/import.md) for gotchas (write-only fields, normalization drift).
