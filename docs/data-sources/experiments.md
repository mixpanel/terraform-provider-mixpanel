# mixpanel_experiments (Data Source)

Lists all experiments in a Mixpanel project. Returns raw IDs and composite import IDs for bulk adoption workflows.

## Example Usage

```terraform
data "mixpanel_experiments" "all" {
  project_id = 1234567
}

# Bulk import experiments into Terraform state
import {
  for_each = toset(data.mixpanel_experiments.all.import_ids)
  to       = mixpanel_experiment.imported[each.value]
  id       = each.value
}

resource "mixpanel_experiment" "imported" {
  for_each = toset(data.mixpanel_experiments.all.ids)
  # lifecycle block prevents Terraform from modifying imported experiments
  lifecycle {
    ignore_changes = all
  }
}
```

See the [bulk import guide](../guides/import.md) for detailed workflows.
