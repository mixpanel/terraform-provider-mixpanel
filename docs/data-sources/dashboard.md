# mixpanel_dashboard (Data Source)

Fetches a Mixpanel dashboard — a Board that arranges saved reports into a shareable view. See also [`mixpanel_dashboard` resource](../resources/dashboard.md).

## Example Usage

```terraform
data "mixpanel_dashboard" "product_kpis" {
  project_id   = 1234567
  dashboard_id = 707
}
```

Only `dashboard_id` and `project_id` are inputs; the remaining attributes are populated from the fetched dashboard.
