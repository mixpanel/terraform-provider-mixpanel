# mixpanel_custom_propertys (Data Source)

Lists every Mixpanel custom property in a project — use it to discover custom property IDs and to bulk-import with `for_each`. See also [`mixpanel_custom_property` data source](custom_property.md) and [`mixpanel_custom_property` resource](../resources/custom_property.md).

## Example Usage

```terraform
data "mixpanel_custom_propertys" "all" {
  project_id = 1234567
}
```

Returns `ids` (list of raw custom property IDs) and `import_ids` (list of `PROJECT_ID:PROPERTY_ID` composites ready to feed `for_each` import blocks). See the [import guide](../guides/import.md) for the bulk-import pattern.

## Bulk import with `for_each`

Adopt every custom property in the project in one pass: the list data source's `import_ids`
feed a `for_each` [import block](../guides/import.md), and `-generate-config-out`
scaffolds each resource body for review before you apply.

```terraform
data "mixpanel_custom_propertys" "all" {}

# One import per custom property. Both for_each iterate import_ids, so the import block
# and the resource address share the same instance key.
import {
  for_each = toset(data.mixpanel_custom_propertys.all.import_ids)
  to       = mixpanel_custom_property.this[each.key]
  id       = each.value
}

resource "mixpanel_custom_property" "this" {
  for_each = toset(data.mixpanel_custom_propertys.all.import_ids)
  # Body scaffolded by `terraform plan -generate-config-out=generated.tf`,
  # then reviewed and edited before apply.
}
```

Run `terraform plan -generate-config-out=generated.tf`, review the generated
configuration, then `terraform apply` to import every custom property. Set `project_id`
on the data source to target a non-default project. See the
[import guide](../guides/import.md) for gotchas (write-only fields, normalization drift).
