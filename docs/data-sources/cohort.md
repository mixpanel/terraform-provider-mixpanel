# cohort (Data Source)

Fetches a Mixpanel cohort — a saved user segment defined by behavioral or property criteria. See also [`mixpanel_cohort` resource](../resources/cohort.md).

## Example Usage

```terraform
data "mixpanel_cohort" "power_users" {
  project_id = 1234567
  cohort_id  = 303
}
```

Only `cohort_id` and `project_id` are inputs; the remaining attributes are populated from the fetched cohort.
