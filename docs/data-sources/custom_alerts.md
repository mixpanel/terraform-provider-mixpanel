# custom_alerts (Data Source)

Lists every Mixpanel custom alert in a project — use it to discover alert IDs and to bulk-import with `for_each`. See also [`mixpanel_custom_alert` data source](custom_alert.md) and [`mixpanel_custom_alert` resource](../resources/custom_alert.md).

## Example Usage

```terraform
data "mixpanel_custom_alerts" "all" {
  project_id = 1234567
}
```

Returns `ids` (list of raw custom alert IDs) and `import_ids` (list of `PROJECT_ID:ALERT_ID` composites ready to feed `for_each` import blocks). See the [import guide](../guides/import.md) for the bulk-import pattern.
