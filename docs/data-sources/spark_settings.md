# spark_settings (Data Source)

Retrieves settings for **Spark** — Mixpanel's AI assistant that provides intelligent insights and automated analysis.

## Example Usage

```terraform
data "mixpanel_spark_settings" "org" {
  organization_id = 7654321
}
```

Only `organization_id` is an input; the `settings` attribute is populated from the fetched object. For the resource counterpart, see [`mixpanel_spark_settings`](../resources/spark_settings.md).
