# Phase 0 Documentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the committed `docs/` corpus so it sells infrastructure-as-code for product analytics to a non-Terraform Mixpanel audience and lets practitioners use the provider correctly — accurate examples, two narrative guides, recalibrated trust posture, and all 89 reference pages on one canonical pattern.

**Architecture:** Pure documentation + adjacent-correctness edits (guide example `.tf`s, a Makefile guard, template sync). No Go changes. Every HCL example is verified attribute-by-attribute against the generated schema before it ships. Work lands as wave-scoped commits on branch `docs-phase-0`.

**Tech Stack:** Markdown (Terraform Registry flavor), HCL examples, `grep`/`ripgrep` for audits, optional `terraform validate` via `dev_overrides`.

## Global Constraints

- **Docs are hand-curated.** Never run `tfplugindocs generate` or wire it into `make docs`. Only `templates/index.md.tmpl` exists as a template; regeneration would wipe the corpus. (gen/README.md step 6.)
- **No unverified examples.** Every HCL attribute must exist in `internal/provider/resource_<entity>/*_gen.go`, `datasource_<entity>/*_gen.go`, the hand-injected attrs in `internal/provider/<entity>_resource.go`, or `<entity>_spec.go`. JSON-blob payloads must satisfy the plan-time validation rules on their page. Prefer copying from `examples/resources/<type>/resource.tf` or `*_acc_test.go` (live-verified) over authoring fresh.
- **No internal leakage in `docs/`.** Forbidden strings: `GREEN-10`, `GREEN-12`, `ARB` (as a standalone term), `api-spec.yml`, `extra="allow"`, `FE editor`, `frozen spec`, `production-tested`, `stored in the database`, `BOARDS_DASHBOARD_BOOKMARK_TYPES`, pydantic docstrings, spec numbers (`045`/`047`).
- **Product vocabulary leads, Terraform type follows:** "a Mixpanel **Board** (`mixpanel_dashboard`)". Gloss Terraform jargon (taint, ForceNew, Optional+Computed) on first use per page.
- **Trust/alpha language lives only in `index.md`.** No per-page alpha warnings.
- **Cross-links are real relative markdown links within `docs/`.** Links must not escape `docs/` except as absolute `https://github.com/mixpanel/terraform-provider-mixpanel/...` URLs.
- **Claim discipline:** never "first/only" analytics provider. Allowed framing: breadth + depth of the analytical surface, with the dated comparison (PostHog official provider ≈18 resources; Amplitude/Heap none first-party; this provider 43 resources + 46 data sources).
- **Commit per task** with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
